# 📡 Multi-Market AI Signal Radar & Web Dashboard

ระบบสแกนหาจังหวะซื้อ-ขาย (Buy/Sell) อัตโนมัติสำหรับ **หุ้นไทย (SET), หุ้นสหรัฐฯ (US Stocks), และคริปโตเคอร์เรนซี (Crypto)** ทำงานบน **GitHub Actions** ฟรี 24 ชั่วโมง พร้อมระบบแจ้งเตือนเข้า **Discord Webhook** และหน้าเว็บแดชบอร์ดดูผลลัพธ์แบบเรียลไทม์บน **GitHub Pages**

---

## 🚀 ฟีเจอร์หลักของระบบ
- **ครอบคลุม 3 ตลาดสำคัญ:** แยกรายชื่อสินทรัพย์เก็บเป็นไฟล์ JSON อิสระในโฟลเดอร์ `lists/` ง่ายต่อการจัดการและนำไปใช้ต่อ
- **คำนวณอินดิเคเตอร์อัตโนมัติ (Timeframe 15m):** ใช้ RSI (14), EMA (9/21 Crossover), และ Volume Spike พร้อมประเมินจุดทำกำไร (TP) และจุดตัดขาดทุน (SL) ด้วยค่า ATR
- **แจ้งเตือนเข้า Discord ทันที:** ส่งข้อความแจ้งเตือนพร้อมสีสถานะเขียว/แดง และมีระบบ **Cooldown (4 ชั่วโมง)** ป้องกันการแจ้งเตือนตัวเดิมซ้ำ ๆ
- **Web Dashboard UI (Dark Mode):** หน้าเว็บสวยงาม ทันสมัย รองรับการกรองแยกตามตลาดและสถานะสัญญาณ

## 📂 โครงสร้างโปรเจกต์ (Project Structure)

```text
market-scanner/
├── .github/

├── index.html                # หน้าเว็บ Dashboard สำหรับ GitHub Pages
└── requirements.txt          # รายชื่อไลบรารี Python ที่ต้องใช้
